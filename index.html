Hostel & Bursary Tool

Turn the gate log into a boarding fee report — no stress.

Upload the attendance file from the gate, tell us the dates and the rate, and this page builds a clean, ready-to-print Excel report — the kind you can hand straight to the bursar. Nothing leaves your computer; everything happens right here in your browser.

  1. 1

    Upload the attendance file

    This is the .xls or .xlsx file exported from the gate / biometric machine.

  2. 2

    Tell us the details

    These settings decide which dates are covered and how the boarding fee is worked out.

    The file's Location ID column tells us which hostel a student belongs to — 1 is matched to "Hostel 1 name" above, 2 to "Hostel 2 name". Any other value is labelled "Unknown".

  3. 3

    Generate the report

    This builds the standard Hostel Absentees report — an Excel file and a PDF — and downloads both straight to your device.
